# Seller-bot + mini CRM

**ИИ-продавец для Telegram, WhatsApp и Instagram со встроенной мини-CRM.**
Один ИИ-менеджер ведёт переписку с клиентами во всех мессенджерах, подбирает товар из каталога,
отрабатывает возражения, принимает оплату и передаёт горячих клиентов живым менеджерам —
карточкой с кнопками в группу Telegram. Всё, что меняется часто (товары, цены, промпты, база
знаний, реквизиты, каналы), настраивается в веб-админке без программиста.

*An open-source AI sales assistant for Telegram, WhatsApp and Instagram with a built-in mini CRM:
omnichannel inbox, lead cards with buttons in a Telegram group, payments, follow-ups and reports.
Python · FastAPI · aiogram 3 · SQLAlchemy · SQLite. UI and prompts are in Russian.*

Проект открыт для совместной доработки — см. [CONTRIBUTING.md](CONTRIBUTING.md).

## Что умеет

### ИИ-продавец
- **Три канала в одном движке:** Telegram (long-polling), WhatsApp Cloud API и Instagram Direct
  (через Meta). Один клиент — один профиль, где бы он ни писал.
- **Любая OpenAI-совместимая модель:** OpenAI, DeepSeek, OpenRouter, Gemini (совместимый режим),
  локальная Ollama. Ключ и модель меняются в админке.
- **Методика продаж «Понять → Сузить → Посоветовать → Закрыть»** зашита в системный промпт;
  персону, приветствие и пошаговый скрипт владелец переписывает в админке.
- **Портрет клиента:** после каждого ответа бот в фоне собирает город, язык, роль, чувство, мотив,
  возражения и вопросы без ответа — и код подбирает правила «как говорить с этим человеком»
  (коротко, по-казахски, без нажима и т. п.).
- **Инструменты вместо обещаний:** каталог и карточка товара, поиск по базе знаний, создание заказа
  и ссылки на оплату, проверка оплаты, отправка фото и документов, запись контакта, перезвон,
  передача человеку, напоминание «вернуться позже».
- **Голос:** распознаёт входящие голосовые и может отвечать голосом (ElevenLabs).
- **Детерминированные вещи — кодом, а не промптом:** заявки, отправка материалов по просьбе «фото»,
  выдача доступа только после подтверждённой оплаты.

### Мини-CRM (веб-админка)
- **💬 Диалоги** — общий инбокс по всем каналам; оператор может перехватить диалог у бота и ответить
  сам (текст, фото, файлы, голос). Есть PWA и web-push, а также зеркало диалогов в темы Telegram-группы.
- **📋 Заявки** — каждая передача клиента человеку становится карточкой в теме Telegram-группы
  менеджеров с кнопками: «Забрал в работу» → «В работе» → «В ожидании» / «Продажа» / «Отказ» /
  «Не целевой». Чужую карточку трогать нельзя. «В ожидании» с датой возвращает карточку в
  назначенный день. Утренняя сводка в 9:00: мини-отчёт + списки «Не забраны» и «В работе» со
  ссылками на карточки. В админке — фильтры, история «что сделано», отчёт по менеджерам
  (скорость реакции, продажи), выгрузка в Excel и CSV-конверсии для Google Ads.
- **📦 Товары и 🧾 Заказы** — каталог, способы выдачи (ссылка/текст, инвайт в закрытый канал),
  подтверждение ручных оплат по чеку.
- **💳 Оплата** — ручная (перевод + чек) и шлюзы: Halyk ePay, FreedomPay, ЮKassa, CryptoBot;
  единая страница оплаты `/pay/{код}`.
- **💚 Лояльность и 📣 Рассылки** — дни рождения, «как дела», рассылки по сегментам; дожим
  молчащих клиентов и брошенных заказов по расписанию.
- **📚 База знаний, 🖼 Медиатека, 📄 Документы** — FAQ и возражения, картинки и файлы, которые бот
  отправляет сам по смыслу запроса.
- **🧠 Обучение и 📊 Аналитика чатов** — стиль общения из реальных переписок, разбор диалогов
  моделью, отчёт в Word.
- **🎯 Воронки и 🎨 Креативы** — лендинги-ссылки `/l/{код}` с меткой рекламы, которая доходит до заявки.
- **🚀 Мастер настройки** — пошаговый запуск для нового владельца.

## Быстрый старт (локально)

Нужен Python 3.11+.

```bash
git clone https://github.com/kirillzakup/seller-bot-mini-crm.git
cd seller-bot-mini-crm
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.main
```

Откройте <http://localhost:8000/admin>.

> **Логин и пароль по умолчанию: `admin` / `admin`.**
> Это только для первого входа. Перед тем как открывать админку в интернет, задайте
> свои `ADMIN_USERNAME`, `ADMIN_PASSWORD` и длинный `SECRET_KEY` в `.env` — при пароле `admin`
> приложение пишет предупреждение в лог.

Дальше всё настраивается в админке (**🚀 Мастер настройки**):
1. **Токен Telegram-бота** от [@BotFather](https://t.me/BotFather) — бот стартует сразу после сохранения.
2. **Ключ и модель ИИ** (OpenAI-совместимый API).
3. **Группа менеджеров:** добавьте бота в группу с темами, укажите её ID в «Настройках», затем в
   нужной теме отправьте `/заявки_сюда`. Каждый менеджер один раз пишет `/менеджер Имя Фамилия`.
4. **Товары, база знаний, способы оплаты.**
5. По желанию — WhatsApp/Instagram (раздел **📡 Каналы**, нужен Meta-аккаунт разработчика) и голос.

Без ключа ИИ бот не падает: отвечает вежливой заглушкой.

## Запуск на сервере (Docker)

```bash
cp .env.production.example .env   # заполните значения
docker compose up -d --build
docker compose logs --tail=20 sellerbot   # ждём «Run polling»
curl http://127.0.0.1:8000/health          # {"status":"ok"}
```

Один контейнер: бот + FastAPI + планировщик. База SQLite лежит в docker-томе `sellerbot-data`.
Пример конфига nginx — в `deploy/`, пошагово — в [DEPLOY.md](DEPLOY.md).

## Переменные окружения

Полный список с комментариями — в [.env.example](.env.example). Главное:

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота (можно ввести и в админке) |
| `BASE_URL` | Публичный адрес — от него строятся ссылки на оплату, лендинги, вебхуки |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | Вход в админку, по умолчанию `admin` / `admin` |
| `SECRET_KEY` | Подпись сессий админки — длинная случайная строка |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | Модель ИИ (переопределяется в админке) |
| `SITE_ORIGINS` | Адреса вашего сайта, чья форма шлёт заявки в `POST /leads` |
| `TIMEZONE`, `CURRENCY` | По умолчанию `Asia/Almaty`, `KZT` |

Ключи WhatsApp/Instagram, платёжных шлюзов и голоса вводятся в админке и хранятся в базе.

## Как устроено

```
app/
  main.py            FastAPI-приложение, запуск бота и планировщика
  channels/          Telegram, WhatsApp+Instagram (Meta), общий приём входящих dispatch.py
  sales/             ИИ-менеджер: промпт, инструменты, портрет клиента, методика продаж
  services/          заказы, заявки, сводки, рассылки, отчёты, медиа, настройки
  bot/handlers/      Telegram: каталог, оплата, кнопки заявок, инбокс операторов
  admin/             веб-админка (Jinja2 + HTMX + Tailwind)
  payments/          ручная оплата и шлюзы
  fulfillment/       выдача товара после оплаты
  db/                модели SQLAlchemy и миграция колонок
tests/               pytest, 330+ тестов
```

Подробнее — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Разработка

```bash
PYTHONIOENCODING=utf-8 python -m pytest -q    # все тесты должны быть зелёными
python -m ruff check app/ tests/              # линтер, длина строки 100
```

- Новая таблица создаётся сама. **Новая колонка в существующей таблице** — добавьте её в список
  `wanted` в `app/db/base.py::_ensure_sqlite_columns`, иначе на уже работающей базе её не будет.
- Всё, что должно произойти гарантированно (заявка, оплата, выдача доступа), делайте кодом —
  промпт это не гарантирует.
- Комментарии и тексты интерфейса — на русском.
