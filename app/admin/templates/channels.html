🟢 Coexistence — видеть переписку в приложении WhatsApp Business

Рекомендуемый способ: подключите существующий номер из приложения WhatsApp Business — бот отвечает, а вы видите все сообщения в приложении. Сначала заполните App ID, App Secret и Config ID выше и нажмите «Сохранить», затем:

Подключить через Embedded Signup →
Что нужно подготовить в кабинете Meta
  1. Добавьте продукт WhatsApp в приложение.
  2. Создайте конфигурацию Embedded Signup (нужен «Вход через Facebook для компаний») → скопируйте Config ID в поле выше.
  3. App ID и App Secret — из «Настройки → Основное».
  4. Нажмите кнопку выше и в окне Facebook выберите ваш номер из приложения WhatsApp Business.
Подключить вручную (только Cloud API, без приложения)
  1. Meta → ваше приложение → Настройки → Основное → скопируйте «Секрет приложения» в поле App Secret выше.
  2. WhatsApp → Конфигурация → Webhook: вставьте Callback URL и Verify Token (из блока выше), «Проверить и сохранить», подпишитесь на поле messages.
  3. WhatsApp → Настройка API: скопируйте «ID номера телефона» → поле Phone Number ID.
  4. Постоянный токен: Бизнес-настройки → Системные пользователи → токен с правом whatsapp_business_messaging → поле Access Token. (Временный токен из «Настройка API» живёт 24 ч — только для теста.)
  5. Поставьте галочку «Включён» и сохраните. Напишите на ваш WhatsApp-номер — бот ответит.

Как подключить Instagram — по шагам
  1. Аккаунт Instagram — профессиональный (бизнес). В кабинете Meta добавьте продукт «Instagram» → «Настройка API с входом через Instagram».
  2. Назначьте аккаунт тестировщиком Instagram (Роли → Тестировщики Instagram) и примите приглашение в самом Instagram.
  3. Instagram → Настройка API → шаг 2: «Сгенерировать маркер» → войдите в аккаунт → токен (IGAA…) в поле Access Token. Числовой ID рядом → поле Instagram ID.
  4. Instagram App Secret — вверху той же страницы («Секрет приложения Instagram» → «Показать») → поле ниже. Нужен для проверки подписи входящих.
  5. Webhooks: Callback URL и Verify Token — из блока выше; подпишитесь на поле messages. Доставка входящих включается после проверки приложения (App Review).
  6. Поставьте «Включён» и сохраните. Токен живёт 60 дней и продлевается ботом автоматически.
